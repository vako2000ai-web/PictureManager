# PictureManager

Локальный менеджер фотоархива: находит фото и видео на дисках, ведёт каталог в SQLite, выявляет точные дубли (SHA-256), раскладывает файлы по датам съёмки `ГГГГ/ММ/ДД` и конвертирует HEIC в JPEG. Интерфейс — в браузере, сервер слушает только `127.0.0.1`.

## Установка и запуск

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -e ".[dev]"
.venv\Scripts\python -m app          # откроется http://127.0.0.1:8765
```

Параметры: `--port 8765`, `--data <каталог>` (база, миниатюры, настройки; по умолчанию `./data`), `--no-browser`.

Тесты: `.venv\Scripts\python -m pytest`.

### FFmpeg (для видео)

Нужен `ffprobe` (дата съёмки видео) и `ffmpeg` (миниатюры видео). Установите FFmpeg и добавьте его в `PATH` либо укажите пути в настройках. Без него приложение работает: дата видео берётся из имени файла или времени изменения, вместо миниатюры показывается заглушка, а в интерфейсе появляется предупреждение.

## Как это работает

1. **Источники.** Добавьте каталоги или диски и запустите сканирование. Повторный скан обрабатывает только новые и изменённые файлы. Диск опознаётся по серийному номеру тома, поэтому смена буквы не создаёт дублей записей.
2. **Каталог.** Файлы группируются по дате съёмки: EXIF или метаданные видео, затем дата в имени файла, затем время изменения. Дату можно задать вручную, она не затирается повторным сканированием. Файлы одной съёмки (RAW+JPEG, Live Photo) связаны и ездят вместе.
3. **Дубли.** Сначала сравнивается размер, SHA-256 считается только для файлов с совпавшим размером. Лишние копии переносятся в карантин `_duplicates`, а не удаляются, и их можно восстановить.
4. **Перемещение.** Строится план с предпросмотром (число файлов, объём, конфликты имён, свободное место). Перемещение выполняется только после подтверждения.
5. **HEIC → JPEG.** Ориентация применяется к пикселям, EXIF и ICC-профиль переносятся. Оригинал остаётся на месте; в карантин его можно отправить отдельным действием.

## Безопасность перемещения

- Сканер только читает файлы.
- В пределах одного тома используется переименование. Между томами файл копируется во временный файл, SHA-256 копии сверяется с источником, и только потом оригинал удаляется.
- Каждая операция пишется в журнал до и после выполнения. После сбоя прерванные операции определяются по журналу при запуске: доводятся, если копия подтверждена, иначе отменяются.
- Перед операцией сверяются размер и время изменения файла; изменённые файлы пропускаются.
- Существующие файлы никогда не перезаписываются: при конфликте имени добавляется суффикс `_1`, `_2`, а точная копия уходит в карантин.
- Выполненный план можно откатить. Файлы, изменённые после перемещения, при откате пропускаются.

## Настройки

Шаблон папок (`{YYYY}/{MM}/{DD}`), граница суток (час, по умолчанию 0), качество JPEG (92), политика времени видео (`local` или `machine`), пути к `ffprobe` и `ffmpeg`.

## Ограничения

События, персонажи и распознавание лиц, а также поиск похожих (не идентичных) изображений не реализованы.
