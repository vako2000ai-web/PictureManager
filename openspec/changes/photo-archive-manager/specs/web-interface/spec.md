## ADDED Requirements

### Requirement: Локальный web-сервер
Система SHALL запускаться как локальное приложение, слушающее только `127.0.0.1`, и открывать web-интерфейс в браузере.

#### Scenario: Запуск
- **WHEN** пользователь запускает приложение
- **THEN** интерфейс доступен в браузере на localhost, а из сети недоступен

### Requirement: Экраны управления
Система SHALL предоставлять экраны: источники сканирования, лента каталога по датам, дубли, план и выполнение перемещения, конвертация HEIC, журнал операций.

#### Scenario: Навигация
- **WHEN** пользователь открывает интерфейс
- **THEN** он может перейти к любому из перечисленных экранов

### Requirement: Фоновые задачи и прогресс
Система SHALL выполнять длительные операции как фоновые задачи, показывать прогресс по байтам и файлам в реальном времени и позволять отменять задачу.

#### Scenario: Отображение прогресса
- **WHEN** запущено сканирование или перемещение
- **THEN** интерфейс показывает обработанные байты, файлы и статус без перезагрузки страницы

#### Scenario: Закрытие вкладки
- **WHEN** пользователь закрывает вкладку во время задачи
- **THEN** задача продолжает выполняться, а при повторном открытии интерфейса показывается её актуальное состояние

### Requirement: Миниатюры
Система SHALL показывать миниатюры фото и видео, генерируя их по требованию и кэшируя на диске.

#### Scenario: Первое открытие
- **WHEN** миниатюры файла ещё нет
- **THEN** она создаётся и сохраняется в кэш, при следующем открытии берётся из кэша

#### Scenario: Невозможно создать миниатюру
- **WHEN** миниатюру создать нельзя (например, нет `ffmpeg` для видео)
- **THEN** показывается заглушка, работа интерфейса не нарушается

### Requirement: Подтверждение опасных действий
Система SHALL требовать явного подтверждения перед перемещением, переносом в карантин и переносом оригиналов и показывать перед этим сводку последствий.

#### Scenario: Запуск перемещения
- **WHEN** пользователь нажимает кнопку выполнения плана
- **THEN** система показывает сводку (число файлов, объём) и выполняет операцию только после подтверждения
