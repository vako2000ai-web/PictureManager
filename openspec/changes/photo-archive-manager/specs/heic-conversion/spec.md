## ADDED Requirements

### Requirement: Конвертация HEIC в JPEG
Система SHALL по запросу пользователя конвертировать выбранные HEIC-файлы (по файлам или по каталогу) в формат JPEG.

#### Scenario: Конвертация выбранных файлов
- **WHEN** пользователь выбирает HEIC-файлы и запускает конвертацию
- **THEN** для каждого файла создаётся JPEG, доступный для просмотра в Windows без дополнительных кодеков

#### Scenario: Повреждённый файл
- **WHEN** HEIC-файл не удаётся прочитать
- **THEN** он пропускается, ошибка попадает в отчёт, остальные файлы обрабатываются

### Requirement: Сохранение метаданных
Система SHALL переносить в JPEG EXIF-данные и цветовой профиль исходного файла и MUST сохранять дату съёмки.

#### Scenario: Дата съёмки
- **WHEN** исходный HEIC содержит дату съёмки
- **THEN** созданный JPEG содержит ту же дату съёмки в EXIF

#### Scenario: Цветовой профиль
- **WHEN** исходный HEIC содержит ICC-профиль
- **THEN** созданный JPEG содержит тот же профиль

### Requirement: Корректная ориентация
Система SHALL применять ориентацию изображения к пикселям и сбрасывать тег ориентации в результате, чтобы кадр не поворачивался повторно.

#### Scenario: Повёрнутый снимок
- **WHEN** исходный HEIC содержит тег поворота
- **THEN** JPEG отображается в правильной ориентации в любом просмотрщике

### Requirement: Расположение результата и конфликты имён
Система SHALL помещать JPEG рядом с оригиналом и при совпадении имени добавлять числовой суффикс, не перезаписывая существующие файлы.

#### Scenario: Имя занято
- **WHEN** рядом с оригиналом уже есть файл с именем результата
- **THEN** результат сохраняется с суффиксом `_1`, `_2` и далее

### Requirement: Связь с оригиналом
Система SHALL хранить в каталоге связь «производный файл — оригинал» и добавлять созданный JPEG в каталог с той же датой съёмки, что у оригинала.

#### Scenario: Новая запись
- **WHEN** конвертация завершена
- **THEN** JPEG появляется в каталоге как производный файл и не считается дублем оригинала

### Requirement: Судьба оригинала
Система SHALL сохранять оригинальный HEIC по умолчанию и переносить его в карантин только по отдельному явному действию пользователя.

#### Scenario: Оригинал по умолчанию
- **WHEN** конвертация завершена без дополнительных действий
- **THEN** оригинальный HEIC остаётся на месте

#### Scenario: Перенос оригинала в карантин
- **WHEN** пользователь подтверждает перенос оригиналов сконвертированных файлов
- **THEN** HEIC переносится в карантин, а операция записывается в журнал

### Requirement: Live Photo
Система SHALL конвертировать только HEIC-часть Live Photo и оставлять парный видеофайл без изменений.

#### Scenario: HEIC с парным MOV
- **WHEN** конвертируется HEIC, имеющий парный MOV
- **THEN** MOV не изменяется, связь группы сохраняется

### Requirement: Настройка качества
Система SHALL позволять задавать качество JPEG (по умолчанию 92).

#### Scenario: Изменение качества
- **WHEN** пользователь задаёт качество 80
- **THEN** результат сохраняется с этим значением
